# std::clamp
تابع `std::clamp` که در **C++17** معرفی شد، یکی از ابزارهای بسیار کاربردی و تمیز در کتابخانه استاندارد C++ است. کار این تابع محدود کردن یک مقدار در یک بازه مشخص (بین حداقل و حداکثر) است.

در ادامه راهنمای کاملی از نحوه‌ی کار، سینتکس و مثال‌های آن را بررسی می‌کنیم.


**برای استفاده از `std::clamp` باید هدر `<algorithm>` را به برنامه‌تان اضافه کنید:**

## استفاده از تابع

### حالت اول: استفاده از عملگر مقایسه‌ای پیش‌فرض (`<`)
```cpp
namespace std {
    constexpr const T& clamp( const T& v, const T& lo, const T& hi );
}
```
* **پارامترها:**
  * مقدار `v`: مقداری که می‌خواهید آن را محدود کنید.
  * کران پایین `lo`: حداقل مقدار مجاز.
  * کران بالا `hi`: حداکثر مقدار مجاز.
* **مقدار بازگشتی:**
  * اگر `v` کمتر از `lo` باشد، مقدار `lo` برگردانده می‌شود.
  * اگر `v` بیشتر از `hi` باشد، مقدار `hi` برگردانده می‌شود.
  * در غیر این صورت، خودِ `v` برگردانده می‌شود.

### حالت دوم: استفاده از تابع مقایسه سفارشی (Custom Comparator)
اگر نیاز داشته باشید مقایسه را با قانون دلخواه خودتان انجام دهید:
```cpp
namespace std {
    constexpr const T& clamp( const T& v, const T& lo, const T& hi, Compare comp );
}
```

## ۲. مثال ساده و کاربردی

```cpp
#include <iostream>
#include <algorithm>

int main() {
    int val = 15;
    int min_val = 0;
    int max_val = 10;

    // از آنجا که ۱۵ بزرگتر از ۱۰ است، خروجی روی ۱۰ محدود (Clamp) می‌شود
    int result = std::clamp(val, min_val, max_val);

    std::cout << result << '\n'; // خروجی: 10
}
```

**سناریوهای مختلف برای `std::clamp(v, lo, hi)`:**
1. اگر `v = 5`، `lo = 0` و `hi = 10` باشد ➔ خروجی: **`5`** (درون بازه مجاز)
2. اگر `v = -5`، `lo = 0` و `hi = 10` باشد ➔ خروجی: **`0`** (کمتر از حداقل، محدود شده به `lo`)
3. اگر `v = 20`، `lo = 0` و `hi = 10` باشد ➔ خروجی: **`10`** (بیشتر از حداکثر، محدود شده به `hi`)

---

## ۳. نکات مهم

* **پیش‌شرط (Precondition):** کران پایین نباید از کران بالا بزرگتر باشد (`lo <= hi`). اگر `lo > hi` باشد، رفتار برنامه تعریف‌نشده (Undefined Behavior) خواهد بود.
* **بازگرداندن مرجع (Reference):** تابع `std::clamp` یک مرجع (`const T&`) به مقدار نهایی برمی‌گرداند که از کپی‌های اضافی برای اشیاء پیچیده جلوگیری می‌کند.
* **قابلیت `constexpr`:** این تابع به صورت `constexpr` تعریف شده است، یعنی می‌توان از آن در زمان کامپایل (Compile-time) نیز استفاده کرد.

---

## ۴. مقایسه با کدهای قبل از C++17
پیش از C++17، توسعه‌دهندگان مجبور بودند برای این کار توابع `std::min` و `std::max` را به صورت تو در تو بنویسند که خوانایی کد را کاهش می‌داد:

```cpp
// روش قدیمی (قبل از C++17)
int result = std::max(min_val, std::min(val, max_val));

// روش مدرن (C++17 به بعد)
int result = std::clamp(val, min_val, max_val);
```
