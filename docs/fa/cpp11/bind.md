# `std::bind`

در زبان C++، تابع `std::bind` بخشی از کتابخانه استاندارد قالب‌ها
(**STL**) است و برای متصل‌کردن (**Bind**) یک تابع یا تابع عضو به یک شیء
یا مقدار مشخص استفاده می‌شود.

این تابع با «بایند کردن» یک تابع یا تابع عضو به یک شیء یا مقدار مشخص، یک
شیء تابعی جدید ایجاد می‌کند. این شیء تابعی می‌تواند با تعداد متفاوتی از
آرگومان‌ها یا با ترتیب متفاوتی از آرگومان‌ها فراخوانی شود.

``` cpp
std::bind(function, object/value, arguments...);
```

## پارامترها

-   **`function`**: تابعی است که می‌خواهید آن را Bind کنید. این پارامتر
    می‌تواند شامل اشاره‌گر به تابع، یک شیء تابعی یا اشاره‌گر به تابع عضو
    باشد.

-   **`object/value`**: شیء یا مقداری است که می‌خواهید تابع را به آن Bind
    کنید. در مورد توابع عضو، این پارامتر شیئی است که تابع عضو روی آن
    فراخوانی خواهد شد. برای توابع مستقل (**Free Functions**) این آرگومان
    معمولاً کاربردی ندارد.

-   **`arguments...`**: آرگومان‌های اضافی هستند که هنگام فراخوانی تابع
    باید به آن ارسال شوند. این آرگومان‌ها می‌توانند شامل Placeholderهایی
    مانند `std::placeholders::_1`، `std::placeholders::_2` و غیره باشند.

Placeholderها مشخص می‌کنند آرگومان‌هایی که هنگام فراخوانی شیء تابعی
بازگشتی ارسال می‌شوند، در چه جایگاهی قرار بگیرند.

## مقدار بازگشتی

تابع `std::bind` در C++ یک **شیء تابعی (Function Object)** بازمی‌گرداند
که به آن **Call Wrapper** یا **Binder** نیز گفته می‌شود.

این شیء تابعی، نسخه‌ای Bind‌شده از تابع اصلی یا تابع عضو است. می‌توان آن را
مانند یک تابع معمولی فراخوانی کرد، با این تفاوت که برخی از آرگومان‌های آن
از قبل به مقادیر یا اشیای مشخص متصل شده‌اند.

نوع بازگشتی `std::bind` به موارد زیر وابسته است:

-   تابع یا تابع عضوی که Bind می‌شود.
-   آرگومان‌هایی که به `std::bind` ارسال می‌شوند.
-   Placeholderهایی که برای تعیین محل قرارگیری آرگومان‌ها استفاده می‌شوند.

به همین دلیل، نوع دقیق بازگشتی معمولاً توسط کامپایلر تعیین می‌شود و بهتر
است برای ذخیره آن از `auto` استفاده کنیم.

## مثال

### کاربرد جزئی یا Partial Application

`std::bind` برخی از آرگومان‌ها را از قبل مشخص می‌کند و یک تابع
قابل‌فراخوانی جدید با پارامترهای کمتر ایجاد می‌کند.

![bind](./assets/bind.webp)

``` cpp
#include <functional>
#include <iostream>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    using namespace std::placeholders;

    // آرگومان اول را از قبل برابر 10 قرار می‌دهیم.
    // _1 یعنی اولین آرگومان هنگام فراخوانی بعداً مشخص می‌شود.

    auto add_ten = std::bind(add, 10, _1);

    std::cout << add_ten(5) << "\n";   // 15
    std::cout << add_ten(20) << "\n";  // 30
}
```

در این مثال:

``` cpp
auto add_ten = std::bind(add, 10, _1);
```

آرگومان اول تابع `add` برابر `10` قرار می‌گیرد و آرگومان دوم با استفاده
از `_1` هنگام فراخوانی مشخص می‌شود.

بنابراین:

``` cpp
add_ten(5);   // 10 + 5 = 15
add_ten(20);  // 10 + 20 = 30
```

### راهنمای Placeholderها

Placeholderها مشخص می‌کنند آرگومان‌های ورودی هنگام فراخوانی شیء تابعی در
چه جایگاهی قرار بگیرند.

![placeholder bind](./assets/placeholder_bind.webp)

  Placeholder   توضیح
  ------------- ------------------------------------
  `_1`          اولین آرگومان ورودی هنگام فراخوانی
  `_2`          دومین آرگومان ورودی هنگام فراخوانی
  `_3`          سومین آرگومان ورودی هنگام فراخوانی
  `_N`          آرگومان ورودی شماره N

برای استفاده از Placeholderها می‌توان نوشت:

``` cpp
using namespace std::placeholders;
```

یا به‌صورت کامل از نام آن‌ها استفاده کرد:

``` cpp
std::placeholders::_1
```

## اتصال توابع عضو

### کاربرد اصلی

توابع عضو یک پارامتر پنهان به نام `this` دارند. `std::bind` می‌تواند شیء
موردنظر را برای تابع عضو مشخص کند و در نتیجه، یک تابع قابل‌فراخوانی
ساده‌تر ایجاد شود.

``` cpp
#include <functional>
#include <iostream>
#include <string>

struct Greeter
{
    std::string name;

    void say_hello(const std::string& to) const
    {
        std::cout << name << " says hi to "
                  << to << "!\n";
    }
};

int main()
{
    using namespace std::placeholders;

    Greeter g{"Alice"};

    // شیء را Bind می‌کنیم تا یک تابع قابل‌فراخوانی
    // با شکل void(const std::string&) داشته باشیم.

    std::function<void(const std::string&)> greet =
        std::bind(&Greeter::say_hello, &g, _1);

    greet("Bob");   // Alice says hi to Bob!
}
```

در این مثال:

``` cpp
std::bind(&Greeter::say_hello, &g, _1);
```

-   `&Greeter::say_hello` اشاره‌گر به تابع عضو است.
-   `&g` شیئی است که تابع عضو روی آن اجرا می‌شود.
-   `_1` مشخص می‌کند آرگومان ورودی هنگام فراخوانی `greet` به تابع
    `say_hello` ارسال شود.

در نتیجه، با اجرای:

``` cpp
greet("Bob");
```

خروجی زیر تولید می‌شود:

``` text
Alice says hi to Bob!
```

## استثناها (Exceptions)

خود تابع `std::bind` معمولاً در هنگام دریافت یک تابع نامعتبر، لزوماً
`std::bad_function_call` پرتاب نمی‌کند. اگر آرگومان‌های Bind‌شده از نظر نوع
و ساختار قابل‌قبول باشند، ممکن است شیء Binder ساخته شود، اما خطا هنگام
فراخوانی آن رخ دهد.

استثنای `std::bad_function_call` معمولاً زمانی رخ می‌دهد که یک شیء
`std::function` خالی یا غیرقابل‌فراخوانی اجرا شود.

همچنین ممکن است هنگام ایجاد شیء تابعی، در صورت کافی نبودن حافظه، استثنای
`std::bad_alloc` رخ دهد.

اگر تابع یا تابع عضو Bind‌شده هنگام اجرا استثنا پرتاب کند، آن استثنا از
طریق شیء تابعی بازگشتی به فراخواننده منتقل می‌شود.

### مثال مربوط به `std::bad_function_call`

``` cpp
#include <functional>
#include <iostream>

// تابع نمونه
void myFunction()
{
    std::cout << "This function does something."
              << std::endl;
}

int main()
{
    // یک std::function خالی ایجاد می‌کنیم.
    std::function<void()> func;

    try
    {
        // چون func خالی است، این فراخوانی استثنا ایجاد می‌کند.
        func();
    }
    catch (const std::bad_function_call& e)
    {
        std::cout << "Error: " << e.what() << std::endl;
    }

    return 0;
}
```

### توضیح مثال

در برنامه بالا، یک شیء از نوع `std::function` با نام `func` ایجاد شده
است، اما هیچ تابعی به آن اختصاص داده نشده است؛ بنابراین این شیء خالی
است.

سپس با اجرای:

``` cpp
func();
```

برنامه تلاش می‌کند یک شیء تابعی خالی را فراخوانی کند. در نتیجه، استثنایی
از نوع `std::bad_function_call` پرتاب می‌شود.

این استثنا توسط بلوک `catch` دریافت شده و پیام خطا در خروجی چاپ می‌شود.

نکته مهم این است که این خطا در زمان اجرا (**Runtime**) رخ می‌دهد؛
بنابراین باید مدیریت استثنا مناسبی برای دریافت و کنترل آن در نظر گرفت.

`std::bad_function_call` یک کلاس مشتق‌شده از `std::exception` است و یکی
از استثناهای استاندارد زبان C++ محسوب می‌شود.

## نکته مهم

در C++ مدرن، معمولاً استفاده از **Lambda**ها نسبت به `std::bind` خواناتر
و قابل‌فهم‌تر است. برای مثال، کد زیر همان کار مثال اول را انجام می‌دهد:

``` cpp
auto add_ten = [](int value)
{
    return add(10, value);
};
```

با این حال، `std::bind` همچنان در برخی کدهای قدیمی و بعضی الگوهای
برنامه‌نویسی کاربرد دارد.
