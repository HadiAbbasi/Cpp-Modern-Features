# حلقه `range-based for` در ++C

حلقه **Range-Based For** که از استاندارد **C++11** معرفی شد، روشی ساده، خوانا و ایمن برای پیمایش تمام عناصر یک محدوده (Range) است. این حلقه به‌صورت خودکار آرایه‌ها، رشته‌ها و کانتینرهای کتابخانه STL را پیمایش می‌کند و نیازی به استفاده از اندیس (`index`) یا اشاره‌گرها (`iterator`) ندارد.

## مزایا

- پیمایش آرایه‌ها، رشته‌ها و کانتینرها را ساده‌تر می‌کند.
- نیاز به مدیریت دستی شمارنده‌ی حلقه و Iterator را از بین می‌برد.
- خوانایی و نگهداری کد را افزایش می‌دهد.
- احتمال خطاهای مربوط به اندیس و خروج از محدوده را کاهش می‌دهد.

---

## مثال اولیه

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3, 4, 5};

    // پیمایش عناصر بردار
    for (int i : v) {
        cout << i << " ";
    }

    return 0;
}
```

### خروجی

```text
1 2 3 4 5
```

در این مثال، حلقه `range-based for` به‌صورت خودکار تمام عناصر `vector` را پیمایش می‌کند؛ بنابراین نیازی به استفاده از `v.size()` یا Iterator نیست.

---

# ساختار (Syntax)

```cpp
for (declaration : range) {
    // دستورات
}
```

## اجزای ساختار

| بخش | توضیح |
|------|------|
| `declaration` | متغیری که در هر تکرار نماینده‌ی یک عنصر از محدوده است. |
| `range` | آرایه، رشته، کانتینر STL یا هر شیء قابل پیمایش (Iterable). |

### مثال

```cpp
for (char ch : str) {
    cout << ch;
}
```

در اینجا `ch` هر بار یکی از کاراکترهای رشته `str` را دریافت می‌کند.

---

# نحوه عملکرد حلقه

مراحل اجرای حلقه به‌ترتیب زیر است:

1. ابتدا ابتدای محدوده (`begin`) و انتهای آن (`end`) مشخص می‌شود.
2. اولین عنصر در متغیر حلقه قرار می‌گیرد.
3. دستورات داخل حلقه اجرا می‌شوند.
4. عنصر بعدی جایگزین متغیر حلقه می‌شود.
5. این روند تا پایان همه عناصر ادامه پیدا می‌کند.
6. پس از آخرین عنصر، حلقه پایان می‌یابد.

# مثال‌های مختلف

## ۱. پیمایش آرایه

```cpp
#include <iostream>
using namespace std;

int main() {

    int arr[] = {10, 20, 30, 40, 50};

    for (int x : arr) {
        cout << x << " ";
    }

    return 0;
}
```

### خروجی

```text
10 20 30 40 50
```

---

## ۲. پیمایش رشته (String)

```cpp
#include <iostream>
using namespace std;

int main() {

    string s = "Hello";

    for (char ch : s) {
        cout << ch << " ";
    }

    return 0;
}
```

### خروجی

```text
H e l l o
```

هر بار متغیر `ch` یکی از کاراکترهای رشته را دریافت می‌کند.

---

## ۳. پیمایش `vector`

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {

    vector<int> nums = {5, 10, 15, 20};

    for (int n : nums) {
        cout << n << endl;
    }

    return 0;
}
```

### خروجی

```text
5
10
15
20
```

---

## ۴. پیمایش `map`

در `map` هر عنصر یک **جفت کلید و مقدار** (`pair`) است؛ بنابراین معمولاً از `auto` استفاده می‌کنیم.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

    map<int, char> m = {
        {1, 'A'},
        {2, 'B'},
        {3, 'C'},
        {4, 'D'}
    };

    for (auto p : m) {
        cout << p.first << " : " << p.second << endl;
    }

    return 0;
}
```

### خروجی

```text
1 : A
2 : B
3 : C
4 : D
```

| عضو | توضیح |
|------|------|
| `p.first` | کلید (Key) |
| `p.second` | مقدار (Value) |

---

## ۵. پیمایش `set`

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {

    set<int> s = {30, 10, 20, 40};

    for (int x : s) {

```

### خروجی

```text
10 20 30 40
```

> عناصر `set` به‌صورت مرتب ذخیره می‌شوند.

# تفاوت کپی و ارجاع (Reference)

## حالت اول: کپی شدن عنصر

```cpp
vector<int> v = {1, 2, 3};

for (int x : v) {
    x *= 2;
}

for (int x : v)
    cout << x << " ";
```

### خروجی

```text
1 2 3
```

در این حالت، `x` یک **کپی** از عنصر است؛ بنابراین مقادیر اصلی تغییر نمی‌کنند.

---

## حالت دوم: استفاده از Reference

```cpp
vector<int> v = {1, 2, 3};

for (int &x : v) {
    x *= 2;
}

for (int x : v)
    cout << x << " ";
```

### خروجی

```text
2 4 6
```

علامت `&` باعث می‌شود `x` مستقیماً به عنصر اصلی اشاره کند و تغییرات روی خود کانتینر اعمال شوند.

---

## حالت سوم: استفاده از `const`

اگر فقط قصد خواندن داده‌ها را دارید، بهترین روش استفاده از `const reference` است.

```cpp
vector<int> v = {10, 20, 30};

for (const int &x : v) {
    cout << x << " ";
}
```

### مزیت

- از کپی شدن عناصر جلوگیری می‌کند.
- اجازه تغییر مقدار را نمی‌دهد.
- برای اشیای بزرگ، عملکرد بهتری دارد.

---

# مقایسه با حلقه معمولی

## حلقه معمولی

```cpp
for (int i = 0; i < v.size(); i++) {
    cout << v[i] << " ";
}
```

## حلقه Range-Based

```cpp
for (int x : v) {
    cout << x << " ";
}
```

| حلقه معمولی | Range-Based For |
|-------------|-----------------|
| نیاز به اندیس دارد | بدون اندیس |
| احتمال خطای محدوده وجود دارد | ایمن‌تر |
| طولانی‌تر | کوتاه و خوانا |
| مناسب برای دسترسی به شماره اندیس | مناسب برای پیمایش عناصر |

---

# چه کانتینرهایی را پشتیبانی می‌کند؟

حلقه `range-based for` روی بیشتر ساختارهای قابل پیمایش کار می‌کند، از جمله:

- آرایه (`array`)
- رشته (`string`)
- `vector`
- `list`
- `deque`
- `set`
- `map`
- `unordered_set`
- `unordered_map`

---

# مزایا

- کد کوتاه‌تر و خواناتر است.
- نیازی به استفاده از اندیس یا Iterator نیست.
- احتمال خطاهای مربوط به پیمایش کاهش می‌یابد.
- با اکثر کانتینرهای STL سازگار است.
- نگهداری و توسعه برنامه را آسان‌تر می‌کند.

---

# جمع‌بندی

حلقه **Range-Based For** بهترین انتخاب برای زمانی است که می‌خواهید تمام عناصر یک مجموعه را به‌ترتیب پیمایش کنید و نیازی به شماره اندیس ندارید. برای تغییر عناصر از **Reference (`&`)** و برای فقط خواندن داده‌ها از **`const &`** استفاده کنید.
