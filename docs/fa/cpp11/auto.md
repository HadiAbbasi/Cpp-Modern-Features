# داده نوع auto

> **نسخه معرفی:** C++11

## مقدمه

کلمه کلیدی `auto` به کامپایلر اجازه می‌دهد نوع متغیر را از روی مقدار اولیه (Initializer) به صورت خودکار تشخیص دهد. این قابلیت باعث کاهش حجم کد، افزایش خوانایی و حذف نیاز به نوشتن نوع‌های طولانی، مانند Iteratorها یا Templateهای پیچیده می‌شود.

> **نکته:** نوع متغیر `auto` در زمان کامپایل مشخص می‌شود و هیچ ارتباطی با تایپ پویا (Dynamic Typing) ندارد.

---

## نحوه استفاده

هنگام تعریف متغیر با `auto` باید **همان لحظه مقدار اولیه به آن اختصاص داده شود**؛ زیرا کامپایلر نوع متغیر را از روی همین مقدار استخراج می‌کند.

```cpp
auto p = persons[1];

p.IncIncome(100);

auto income = p.GetIncome();
```

در مثال بالا، کامپایلر نوع واقعی `p` و `income` را از روی مقدار بازگشتی تشخیص می‌دهد.

---

## استفاده از Reference

به صورت پیش‌فرض، `auto` یک **کپی** از مقدار را ایجاد می‌کند. اگر بخواهید متغیر به همان شیء اصلی اشاره کند، باید از `&` استفاده کنید.

```cpp
auto& p = persons[1];

p.IncIncome(100);

auto income = p.GetIncome();
```

در این حالت، `p` یک Reference به عنصر موجود در `persons` خواهد بود و هر تغییری روی آن مستقیماً روی شیء اصلی اعمال می‌شود.

---

## کاربرد در Iteratorها

یکی از مهم‌ترین کاربردهای `auto` حذف نوع‌های بسیار طولانی است.

در C++03 برای پیمایش یک `std::vector` معمولاً باید نوع کامل Iterator نوشته می‌شد.

### C++03

```cpp
std::vector<int> vec = {2, 3, 4, 5};

for (std::vector<int>::iterator it = vec.begin();
     it != vec.end();
     ++it)
{
    m_vec.push_back(*it);
}
```

همان‌طور که مشاهده می‌شود، نوشتن نوع کامل Iterator طولانی بوده و خوانایی کد را کاهش می‌دهد.

در C++11 می‌توان همان کد را به شکل بسیار ساده‌تری نوشت.

### C++11

```cpp
std::vector<int> vec = {2, 3, 4, 5};

for (auto it = vec.begin();
     it != vec.end();
     ++it)
{
    m_vec.push_back(*it);
}
```

در زمان کامپایل، کامپایلر نوع واقعی `it` را تشخیص داده و `auto` را با نوع مناسب جایگزین می‌کند.

---

## مثال‌های ساده

```cpp
auto a = 6;          // int

auto b = 9.6;        // double

auto c = a;          // int

auto str = "Hello";  // const char*

auto flag = true;    // bool
```

---

## مزایا

- کاهش حجم کد
- افزایش خوانایی
- حذف نیاز به نوشتن نوع‌های طولانی
- مناسب برای Templateها و Iteratorها
- کاهش احتمال خطا هنگام تغییر نوع متغیرها

---

## نکات مهم

- متغیر `auto` **حتماً باید مقدار اولیه داشته باشد**.

```cpp
auto value = 10;   // صحیح

auto value;        // خطا
```

- `auto` به صورت پیش‌فرض مقدار را کپی می‌کند.

```cpp
auto x = obj;
```

- برای نگهداری Reference باید از `&` استفاده کنید.

```cpp
auto& x = obj;
```

- برای نگهداری مقدار به صورت Reference فقط-خواندنی از `const auto&` استفاده کنید.

```cpp
const auto& x = obj;
```

## بهترین کاربردها

استفاده از `auto` در موارد زیر توصیه می‌شود:

- Iteratorها
- Lambda Expressionها
- انواع Template
- انواع بازگشتی طولانی
- کدهای Generic

در مقابل، اگر استفاده از `auto` باعث شود نوع واقعی متغیر برای خواننده نامشخص شود، بهتر است نوع صریح متغیر نوشته شود.

## جمع‌بندی

کلمه کلیدی `auto` یکی از مهم‌ترین قابلیت‌های معرفی‌شده در C++11 است. این قابلیت بدون آنکه سربار زمان اجرا ایجاد کند، خوانایی و نگهداری کد را بهبود می‌دهد و به‌خصوص هنگام کار با Templateها، Iteratorها و نوع‌های پیچیده، باعث ساده‌تر شدن کد می‌شود.
