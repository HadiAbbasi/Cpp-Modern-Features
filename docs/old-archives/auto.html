دستور auto در ++C

استفاده از نوع داینامیک auto برای جلوگیری از تعیین دستی نوع متغیر و تنظیم شدن آن توسط خود کامپایلر است. توجه شود که باید بلافاصله در همان خط، نوع متغیری که به auto اختصاص داده می‌شود مشخص باشد. به بیان بهتر، باید در همان خط تعریف، عمل انتساب (assignment) انجام شود و توسط عملگر = مقداری در متغیر ریخته شود تا کامپایلر خطا ندهد و نوع آن را به درستی تشخیص دهد.

auto p = persons[1];
p.IncIncome(100);
auto income = p.GetIncome();

برای اینکه متغیر assign شده به متغیر auto به صورت رفرنس (Reference) ذخیره شود، باید از & پس از auto استفاده کرد:

auto& p = persons[1];
p.IncIncome(100);
auto income = p.GetIncome();

ساده‌سازی کد با auto

حتماً برای شما هم تعریف متغیری از نوعی که نمی‌دانید یا نام نوع آن بسیار طولانی است (همانند ایتریتورها) اندکی دردسرساز بوده است. به مثال زیر توجه فرمایید:

std::vector<int> vec = {2, 3, 4, 5};

// C++ 03
for (std::vector<int>::iterator it = vec.begin(); it != vec.end(); ++it) {
    m_vec.push_back(*it);
}

همان‌طور که مشاهده می‌کنید، تعریف نوع Iterator برای وکتوری از نوع int سخت و طولانی است و از طرفی نمای چندان جالبی هم ندارد. شما می‌توانید با کمک کلمه کلیدی auto در ++C 11 کار خود را راحت کنید. در واقع، کلمه کلیدی auto در زمان کامپایل توسط کامپایلر برداشته می‌شود و نوع متغیر یا مقداری که به آن نسبت داده می‌شود، جایگزین auto می‌گردد!

// C++ 11: use auto type
for (auto it = vec.begin(); it != vec.end(); ++it) {
    m_vec.push_back(*it);
}

مثال‌های بیشتر

در مورد متغیرهای زیر، نوع داده به صورت خودکار و بر اساس مقدار سمت راست تشخیص داده می‌شود:

auto a = 6;           // a is an integer
auto b = 9.6;         // b is a double
auto c = a;           // c is an integer

The auto Keyword in C++

Using the dynamic auto type avoids manually specifying the variable type, allowing the compiler to deduce it automatically. Note that the type of the value assigned to auto must be determinable on the exact same line. In other words, an assignment must occur on the same line the auto variable is declared, using the = operator, so the compiler can deduce the type without errors.

auto p = persons[1];
p.IncIncome(100);
auto income = p.GetIncome();

To assign the variable to an auto variable as a reference, you must use & after auto:

auto& p = persons[1];
p.IncIncome(100);
auto income = p.GetIncome();

Simplifying Code with auto

Surely, defining a variable with an unknown or very long type name (such as iterators) can be a bit troublesome and difficult. Consider the following example:

std::vector<int> vec = {2, 3, 4, 5};

// C++ 03
for (std::vector<int>::iterator it = vec.begin(); it != vec.end(); ++it) {
    m_vec.push_back(*it);
}

As you can see, defining an Iterator type for a vector of int is hard, lengthy, and doesn't look very clean. You can make your life easier with the auto keyword in C++11. In fact, the auto keyword is replaced by the compiler at compile-time with the actual type of the variable or the value assigned to it!

// C++ 11: use auto type
for (auto it = vec.begin(); it != vec.end(); ++it) {
    m_vec.push_back(*it);
}

More Examples

For the following variables, the data type is automatically deduced based on the assigned value:

auto a = 6;           // a is an integer
auto b = 9.6;         // b is a double
auto c = a;           // c is an integer
